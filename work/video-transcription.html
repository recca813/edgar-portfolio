Video Transcription and Translation Pipeline

Drop in a video from either direction — a Drive folder or a YouTube link — and get captions, a translation, and a summary back in Docs.

n8n OpenAI Whisper Google Cloud TTS Creatomate Google Docs API

01 / Problem

Turning raw video into captioned, translated, summarized output normally means juggling separate tools for transcription, translation, subtitle timing, and write-up — and doing it by hand for every new video, regardless of where that video came from.

02 / Approach

Rather than force every video through one intake method, the workflow accepts either a Google Drive folder watch or a submitted YouTube URL as the trigger, then converges both paths into the same processing pipeline — so the input source doesn't change the output quality or format.

03 / What Was Built

An n8n workflow with two entry points — a watched Google Drive folder and a YouTube URL submission form — both feeding into a shared pipeline: OpenAI Whisper transcribes the audio, the transcript is translated, and Creatomate generates auto-synced captions timed to the video. Google Cloud TTS handles spoken output where a voiced version of the translation is needed. The final transcript, translation, and summary are written to Google Docs via the Docs API as the delivered artifact.

04 / Outcome

One pipeline handles video intake from two different sources and delivers a captioned, translated, summarized Doc without manual editing at any step in between.
