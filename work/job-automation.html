Agentic Job Automation System

A daily autonomous workflow that finds and filters job listings before I'm awake.

n8n Firecrawl Google Gemini Google Sheets API

01 / Problem

Manually checking job boards every day for relevant openings is slow and easy to fall behind on — especially when filtering for a narrow combination of role type (AI/automation) and location (Dubai or remote) across sites that don't share a common format.

02 / Approach

Rather than checking boards by hand, the workflow runs on a daily schedule and does the filtering itself: scrape first, then let an AI model make the relevance call instead of hand-written keyword rules, so a listing worded differently than expected doesn't slip through un-filtered.

03 / What Was Built

An n8n workflow scrapes job boards via Firecrawl on a daily schedule, then passes each listing to Google Gemini to judge relevance and location against a fixed profile (AI/automation roles, Dubai or remote) before anything gets logged. Listings that pass are appended to a shared Google Sheet as the single source of truth for the day's results. Every fallible step — the scrape, the AI filtering call, the sheet write — has its own retry and error-logging branch, so a bad scrape or an API hiccup doesn't silently drop a day's results.

04 / Outcome

Runs unattended every day, turning a manual daily check across multiple sites into a single filtered list waiting in a spreadsheet each morning.
